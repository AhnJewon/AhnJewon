### 🚜 F.A.S.T. — AIoT 무인 지게차 물류 자동화

> 1/10 스케일 지게차가 자율주행으로 파렛트 구멍에 포크를 꽂아 화물을 이송하는 디지털 트윈 제어 시스템<br/>
> `2026.07 ~ 2026.08` · 6인 팀 (SSAFY 공통 프로젝트, **우수상**) · **담당: 자율주행 파트** (LiDAR · SLAM · Nav2 · 센서 융합 · 포크 기구)

- **데모 3일 전의 침묵 실패** — TF가 끊기고 토픽 구독이 조용히 실패했습니다. 캐시 삭제로 넘기지 않고 `/dev/shm`에 남는 Fast DDS 공유메모리 세마포어 잔여물을 원인으로 규명했고, 단일 보드 통신임에 착안해 UDPv4 로컬 루프백으로 전환했습니다. → **세그먼트 109개 → 4개, 유실률 0%**
- **저속 헌팅 제거** — 정지마찰 문턱을 넘지 못하는 구간에서 P 제어를 폐기하고, 멈춘 동안 듀티를 축적하는 **적분(I) 전용 제어기**로 재설계 → **속도 오차 37% → 4%**
- **센서가 서로를 지우는 문제** — ToF의 clearing 플래그가 LiDAR의 정면 장애물을 밀어내던 현상을 costmap Maximum 병합 특성으로 추적해 레이어를 격리 → 회피 무한 루프 해소
- `ROS2 Humble` `Nav2` `slam_toolbox` `Fast DDS` `Jetson Orin Nano` `ESP32-S3` `C++/Python`

### 🔭 [Serendipity Engine](https://github.com/AhnJewon/serendipity_engine) — 역발상 AI 검색 엔진

> 관심사의 의미적 대척점(Antipode)을 계산하고, 그 사이를 지식 그래프와 벡터 보간으로 이어 주는 필터 버블 탈출 검색기<br/>
> `2025.10 ~ 2026.02` · **1인 개발** (학부 연구 연계)

- 한글 위키백과 덤프에서 **표제어 124만 건**을 정제해 Ko-SBERT 768차원 벡터 DB로 구축
- 유사도 최하위만 뽑으면 문맥 없는 고립 단어가 나오므로, 후보군을 **K-Means(k=5)** 군집화해 안정적인 대척 테마를 선정
- 경로 중간의 의미적 비약은 인접 노드 유사도가 **0.5 미만일 때 내분점 벡터를 재귀 삽입**하는 Gap-Filling 필터로 평탄화
- `Python` `Ko-SBERT` `KeyBERT` `Vector DB` `Wikidata SPARQL` `Kiwi` `Streamlit`
